AutoDesign: Meta-Harness Optimization for Long-Horizon Agentic Design

arXiv

Yaxin Luo, Haobin Jiang, Jialv Zou, Xu Huang, Wenhao Yan, Haodong Li, Zhengrong Yue, Jing Li, Xiaofu Chen, Xiaohan Zhao, Jiacheng Liu, Jiacheng Cui, Zhiqiang Shen, Xiaotong Li

AI Summary

The core problem is that existing model-harness systems for long-horizon agentic design are static and fail to align with human design priors or self-improve. AutoDesign is proposed as a framework where a meta-harness optimizer guides a code agent to recursively improve the harness based on rollout feedback, aligning with human design priors. Applied to paper-to-poster generation with a new PosterBench benchmark, AutoDesign achieved the highest score (78.32), surpassing commercial systems by 7.45 points, and improved performance by 12.4% with its learned harness. It demonstrated efficient autonomous operation and achieved the highest human preference in blind evaluations.

AI Summary

YAVIN: A Unified Architecture for Secure Edge Processing in Memory

arXiv

Shouzhi Fang, William C. Tegge, Md Omar Faruque, Peipei Zhou, Endadul Hoque, Alex K. Jones

AI Summary

The core problem is the lack of secure, private multi-tenant execution for processing-in-memory (PIM), as existing Trusted Execution Environments (TEEs) do not extend trust to in-memory computation. YAVIN proposes a unified TCB that extends the TEE to a dedicated memory region for trusted PIM execution, co-designing PIM implementations of LightSaber KEM and ASCON-128 to enable secure data processing directly in memory. This cryptography-PIM co-design reorganizes computation for authenticated encryption with minimal overhead, achieving over 20x speedup compared to PIM AES. It incurs only 34% (INT8) and 9.3% (INT32) overhead for edge-class LLMs relative to plaintext execution.

arXiv

AI Summary

General-purpose multimodal embedding models for driving video retrieval struggle to distinguish fine-grained, motion-centric events due to reliance on static scene context. This paper introduces TraVEL (Trajectory-Guided Video Embedding Learning), a motion-aware fine-tuning framework that leverages ego-trajectory similarity as a reward within Group Relative Policy Optimization, using trajectories only during training. Decoding Task Progress from VLA Representations

arXiv

Atiksh Bhardwaj, Edward Weiyi Duan, Prithwish Dan, Wei-Chiu Ma, Preston Culbertson

AI Summary

The core problem is the lack of tools to understand internal representations and monitor Vision-Language-Action (VLA) models during deployment. The proposed method involves using mechanistic interpretability to linearly probe the residual stream of a VLA ($π_{0.5}$), identifying that task progress (normalized time remaining) is linearly readable from its activations. Key results show this signal is present in pretrained backbones, generalizes to unseen tasks, and adapts to language counterfactuals. Furthermore, the probe effectively serves as a label-free out-of-distribution detector for stalled task progress, competitive with state-of-the-art methods, demonstrating rich, readable internal semantic representations in VLAs.

UniTexture: Cross-Task Universal Adversarial Textures for Vision-Language-Action Models

arXiv

Yukun Dai, Mingzhe Dai, Tianshi Wang, Fengling Li, Jingjing Li, Lei Zhu

AI Summary

Multitask Vision-Language-Action (VLA) models are vulnerable to adversarial interference, with existing attacks being task-specific and leaving cross-task vulnerabilities unexplored. UniTexture introduces a cross-task universal adversarial texture attack that uses a single textured 3D object, optimized jointly across tasks via a differentiable renderer and targeted action-space objective, to induce deviations in VLA action predictions. arXiv

AI Summary

arXiv

Zixuan Lan, Yanhong Li, Jiawei Zhou

AI Summary

Transformer-based LLMs incur substantial inference cost from high-dimensional matrix multiplications. arXiv

Shivam Vats, Sudarshan Harithas, Mete Tuluhan Akbulut, Arvind Raghunathan, George Konidaris

AI Summary

The core problem is autonomously learning robot skills for sequential tasks under a limited practice budget. The proposed method, Deliberate Practice (DP), computes a provably budget-optimal allocation by using a bilinear program to estimate skill mastery time and the cumulative reward of unlocked task plans, maximizing expected cumulative reward within budget. Key results show DP effectively allows robots to optimally use limited practice time to acquire useful policies and improve long-horizon planning in simulated and real-world manipulation tasks.

arXiv

AI Summary

FIRE-VLA: Failure-Informed Self-Evolution for Vision-Language-Action Models in Autonomous Driving

arXiv

Hao Dou

AI Summary

Reinforcement learning for autonomous driving VLA models struggles when all sampled trajectories are poor, providing only relative failure rankings without identifying behaviors outside failed regions. FIRE-VLA addresses this with a failure-informed self-evolution framework that converts low-reward, low-diversity "unresolved failures" into privileged self-distillation supervision. A frozen round-start model acts as a teacher, observing future trajectories, to guide the current student policy. On nuScenes, FIRE-VLA reduces mean L2 error from 1.848m to 1.500m and lowers evaluation-persistent failure prevalence from 13.03% to 11.20%, mainly by improving rare severe rollouts.
