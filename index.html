AutoDesign: Meta-Harness Optimization for Long-Horizon Agentic Design

arXiv

Yaxin Luo, Haobin Jiang, Jialv Zou, Xu Huang, Wenhao Yan, Haodong Li, Zhengrong Yue, Jing Li, Xiaofu Chen, Xiaohan Zhao, Jiacheng Liu, Jiacheng Cui, Zhiqiang Shen, Xiaotong Li

AI Summary

Existing agentic design systems for transforming multimodal inputs into structured outputs are static and lack recursive self-improvement or alignment with human design priors. AutoDesign is proposed, employing a meta-harness optimizer to guide a code agent in recursively improving the harness based on rollout feedback, aligning with human design priors. A Browser-Native Digital Test Range for Benchmarking 4D Ocean-Glider Planning Algorithms

arXiv

Edward Holmberg, Elias Ioup, Mahdi Abdelguerfi

AI Summary

Real-world evaluation of ocean-glider planning algorithms is resource-intensive, expensive, and lacks the reproducibility needed for comparative analysis. This paper introduces a browser-native, installation-free "digital test range" that transforms selected ocean regions into reproducible 4D experiments, providing a common plan-to-observation contract for benchmarking via Pyodide/WebAssembly. YAVIN: A Unified Architecture for Secure Edge Processing in Memory

arXiv

Shouzhi Fang, William C. Tegge, Md Omar Faruque, Peipei Zhou, Endadul Hoque, Alex K. Jones

AI Summary

Existing Trusted Execution Environments (TEEs) fail to provide secure, private multi-tenant execution directly within memory, limiting trusted computation to the processor and leaving processing-in-memory (PIM) vulnerable. YAVIN proposes a unified Trusted Computing Base (TCB) that extends the TEE to a dedicated memory region, enabling trusted PIM execution by co-designing post-quantum cryptography (LightSaber KEM, ASCON-128) for efficient DRAM. This allows data decryption, processing, and re-encryption within the TEE, treating the memory bus as untrusted. YAVIN achieves over a 20x speedup compared to prior PIM AES implementations and incurs only 9.3-34% overhead for quantized LLM execution relative to plaintext.

Decoding Task Progress from VLA Representations

arXiv

Atiksh Bhardwaj, Edward Weiyi Duan, Prithwish Dan, Wei-Chiu Ma, Preston Culbertson

AI Summary

Vision-language-action (VLA) models currently lack tools for understanding their internal representations and monitoring them during runtime. This work applies mechanistic interpretability to probe the residual stream of a VLA ($π_{0.5}$), revealing that task progress (normalized time remaining) is linearly readable from its activations. This signal is present even in the pretrained backbone, generalizes to unseen tasks, and varies under language counterfactuals, although it doesn't enable direct policy steering. Critically, this linearly readable task progress signal can be used as a simple, label-free Out-of-Distribution detector for stalled progress, performing competitively with state-of-the-art methods.

UniTexture: Cross-Task Universal Adversarial Textures for Vision-Language-Action Models

arXiv

Yukun Dai, Mingzhe Dai, Tianshi Wang, Fengling Li, Jingjing Li, Lei Zhu

AI Summary

Multitask Vision-Language-Action (VLA) models are susceptible to adversarial interference, but existing attacks only target single tasks, leaving widespread cross-task vulnerabilities unexplored. UniTexture introduces a universal adversarial texture by jointly optimizing a single textured 3D object across diverse tasks, instructions, and viewpoints, using a differentiable renderer and a targeted action-space objective to induce action deviations. This single texture reduced VLA task success rates from 90.0% to 48.4%, induced target-aligned action shifts, and exhibited cross-suite and cross-model transfer without re-optimization. These findings reveal systematic, exploitable cross-task vulnerabilities in multitask VLAs.

AI Summary

arXiv

AI Summary

FIRE-VLA: Failure-Informed Self-Evolution for Vision-Language-Action Models in Autonomous Driving

arXiv

Hao Dou

AI Summary

Autonomous driving VLA models using GRPO struggle when all sampled trajectories are poor, leading to "unresolved failures" that don't identify corrective behaviors. FIRE-VLA addresses this by implementing a failure-informed self-evolution framework that converts these unresolved failures into privileged supervision via self-distillation. When low-reward, low-diversity groups occur, a frozen round-start model acts as a teacher observing hidden future trajectories, guiding the student policy alongside active GRPO. This method reduced mean L2 error from 1.848m to 1.500m and evaluation-persistent failure prevalence from 13.03% to 11.20% on nuScenes, primarily by mitigating rare severe rollouts.
