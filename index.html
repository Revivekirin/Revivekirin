Zero-Shot Long-Horizon Dexterous Manipulation via Multi-View 3D-Grounded VLM Reasoning

arXiv

Jisoo Kim, Sangwon Baik, Taeksoo Kim, Sungjoo Kim, Junyoung Lee, Mingi Choi, Hanbyul Joo

AI Summary

The paper addresses the core problem of achieving zero-shot, long-horizon dexterous manipulation by grounding language instructions into executable 3D task plans using multi-view RGB images. The proposed method utilizes a vision-language model (VLM) to generate 2D keypoints and task groundings, which are then lifted to 3D via multi-view fusion combining triangulation and ray voting. These 3D points enable task-conditioned grasp generation for pick-and-place or retrieval of 6D tool trajectories for tool-use. Key results show improved 3D grounding accuracy and execution reliability over baselines, demonstrating zero-shot manipulation of unseen objects and tool-use tasks in novel scenes through closed-loop verification and replanning.

Native Active Perception as Reasoning for Omni-Modal Understanding

ICML

Zhenghao Xing, Ruiyang Xu, Yuxuan Wang, Jinzheng He, Ziyang Ma, Qize Yang, Yunfei Chu, Jin Xu, Junyang Lin, Chi-Wing Fu, Pheng-Ann Heng

AI Summary

Long video understanding models are computationally inefficient, uniformly processing content regardless of relevance, causing cost to scale with video duration even in interactive systems. This paper introduces OmniAgent, a native omni-modal agent that frames video understanding as a POMDP-based iterative Observation-Thought-Action cycle, selectively distilling audio-visual cues into textual memory to decouple reasoning complexity from raw video length. Operationalized via Agentic Supervised Fine-Tuning and Reinforcement Learning with TAURA, OmniAgent achieves positive test-time scaling, improving performance with more reasoning turns. It establishes state-of-the-art performance on ten benchmarks, outperforming models 10x larger (e.g., Qwen2.5-VL-72B) on LVBench.

Modeling Branches for Active Manipulation using Iterative Parameter Estimation

arXiv

Madhav Rijal, Rashik Shrestha, Trevor Smith, Yu Gu

AI Summary

The core problem is achieving delicate, deformation-aware manipulation of diverse plant branches for agricultural robotic tasks. The proposed method builds a tetrahedral finite element model from point-cloud data, iteratively estimates branch material parameters using real deformation observations, and then computes an optimal path with a deformation-aware motion planner. This approach reduced deformation energy by 35.69% on average across varied branches, with an associated 8.10% increase in path length.
