UrbanGround: From Local Perception to Spatial Agency in a Real-Scale City

arXiv

Tianjie Ju, Zheng Wu, Yueqing Sun, Yuhan Cui, Bobo Li, Shengqiong Wu, Pengzhou Cheng, Haodong Zhao, Zongru Wu, Xinbei Ma, Doris Zhang, Kunling Li, Mong-Li Lee, Wynne Hsu, Hao Fei, Qi Gu, Gongshen Liu, Zhuosheng Zhang

AI Summary

TTPO: Test-Time Policy Optimization

arXiv

Aozhe Wang, Zhengxi Lu, Jianze Wang, Shangke Lv, Ying Liu, Weiming Lu, Jun Xiao, Yueting Zhuang, Hua Yang, Qianglong Chen, Yongliang Shen

AI Summary

Post-training methods like RL and OPSD boost LLM mathematical reasoning but require ground-truth labels, precluding test-time training (TTT) and making fragile majority-vote pseudo-labels prone to corruption. TTPO addresses this by proposing an asymmetric objective that distills agreeing rollouts via OPSD while penalizing disagreeing ones with Grouped RL, further refined by token-level selection to remain robust to pseudo-label errors. Without any labels, TTPO matches label-supervised OPSD on five competition-level benchmarks, boosting Qwen3-1.7B's TTT performance from 38.0% to 45.2%, and demonstrates strong cross-task generalization.

Boosting LLM Exploration via Weak-Model Guidance in RLVR

arXiv

Xingyu Shen, Huishuai Zhang, Peng Li, Yinchun Wang, Dongyan Zhao

AI Summary

Reinforcement Learning with Verifiable Rewards (RLVR) improves LLM reasoning but suffers from policy entropy collapse, narrowing reasoning coverage and degrading pass@$k$ for large $k$. This paper proposes Weak-Model Guidance (WMG), where the target LLM generates answers based on partial reasoning trajectories provided by a smaller, weaker language model, using these unfamiliar prefixes to encourage exploration. WMG consistently outperforms vanilla RLVR on mathematical benchmarks, substantially expanding reasoning coverage, particularly for larger $k$, while efficiently mitigating entropy collapse without complex additions.

Scaling Graph Neural Networks for Friend Recommendation: Multi-Hash User Embeddings and Temporal Neighbor Sampling

arXiv

Maksim Utushkin, Andrei Ovsiannikov, Alexander D'yakonov

AI Summary

Scaling Graph Neural Networks (GNNs) for friend recommendation on massive production social graphs presents challenges with large ID embedding tables and inefficient temporal neighbor sampling. This paper proposes using multi-hash ID embeddings as the primary node representation and implementing temporal neighbor sampling with timestamp-sorted CSR storage and binary search. The method reduces ID-embedding table size by over 98% and sampling cost from $O(deg(v))$ to $O(\log(deg(v)))$, while preserving ranking quality. In production, it scaled to 194M users and increased friend additions by 16% in online A/B tests.

AI Summary

The core problem addresses the unclear comparison and choice among existing fusion paradigms for consolidating multiple reinforcement learning with verifiable rewards (RLVR) capabilities in large language models. arXiv

A Finite Sample Analysis for Quantile Temporal Difference Learning in Distributional Reinforcement Learning

arXiv

Zijie Cheng, Xiang Li, Yang Peng, Zhihua Zhang

AI Summary

This paper establishes the first global finite-sample guarantee for synchronous quantile temporal-difference (QTD) learning in tabular distributional reinforcement learning. The proof separates a global comparison argument using $W_\infty$ contraction from a local linearization with a variance-sensitive martingale analysis. Key results show the leading last-iterate fluctuation is $\widetilde O\bigl(T^{-a/2}/\sqrt{1-γ}\bigr)$ for specific step-sizes, crucially without polynomial dependence on the number of quantiles. While the global transient can still depend on the smallest Bellman-target density, this work sharply distinguishes local stochastic fluctuations from global sample complexity.

arXiv

AI Summary

TADP proposes a Task-Aware Deformable Prediction method, employing a triple feature refinement aggregation module and a multi-scale feature aggregation block for adaptive feature processing.
